
# 🚀 Space Shooter Game

A fun and interactive Space Shooter Game developed using HTML, CSS, and JavaScript. Control your spaceship, shoot incoming enemies, earn points, and survive the galaxy battle!

## 📌 Project Overview

Space Shooter is a browser-based arcade game where players control a spaceship and destroy incoming enemy aliens.

The objective is to shoot as many enemies as possible, increase your score, and survive without losing all your lives.

## ✨ Features

- 🚀 Spaceship movement
- 👾 Enemy alien attacks
- 🔫 Shooting bullets
- ⭐ Real-time score tracking
- ❤️ Three player lives
- 💥 Collision detection
- 📈 Increasing game difficulty
- 🔄 Restart game option

## 🛠️ Technologies Used

- HTML5 – Game structure
- CSS3 – Game design and styling
- JavaScript – Game logic and functionality

## 🎮 Game Controls

| Key | Action |
|-----|--------|
| ⬅️ Left Arrow | Move Left |
| ➡️ Right Arrow | Move Right |
| SPACEBAR | Shoot Enemies |

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in Google Chrome.
4. Click the START / RESTART button.
5. Start playing!
